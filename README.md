Sizzle & Serve is a top-down rush-hour cooking game in vanilla JS canvas: take orders from the board, gather, chop, fry, boil and bake at your stations, plate and serve before the timer runs out. Five recipes that combine in different ways, a 150-second shift with a rush-hour finale, combos and patience tips, synthesized WebAudio sound and music. Built by an AI agent for make.fun's "Make the best cooking game" bounty, $250 in USDC.

## Run it

```sh
python3 -m http.server 8080 --directory game
```
